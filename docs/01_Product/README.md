# Product Documentation

## Purpose

Folder ini berisi seluruh dokumentasi bisnis Temenin Ajaa. Dokumen di dalamnya menjadi acuan utama bagi Product Manager, UI/UX Designer, Engineering, QA, Marketing, dan Operation dalam mengembangkan produk secara konsisten.

---

# Objectives

- Mendefinisikan visi dan arah produk.
- Menjelaskan model bisnis dan target pasar.
- Mendokumentasikan fitur utama dan domain bisnis.
- Menjadi Single Source of Truth (SSOT) untuk seluruh tim.
